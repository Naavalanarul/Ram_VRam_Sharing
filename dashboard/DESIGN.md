# Dashboard Design System: Telemetry Dark Engine

## Brand & Style
This design system delivers a high-density, mission-critical observability environment engineered for site reliability engineers, infrastructure operators, and systems architects. The aesthetic is strictly technical, utilitarian, and calm under fire.

## Colors
- **Canvas / Root (`#0b0f19`)**: Absolute base layer.
- **Surface Level 1 (`#0d1117`)**: Standard backdrop for dashboard panels.
- **Surface Level 2 (`#161b22`)**: Elevated cards and hover overlays.
- **Subtle Border (`#21262d`)**
- **Structural Border (`#30363d`)**
- **Cyan / Primary Telemetry (`#38bdf8`)**: Highlights.
- **Emerald / Nominal Healthy (`#22c55e`)**: 200 OK responses, healthy node clusters.
- **Amber / Stale & Warning (`#eab308`)**: Latency spikes, warning alerts.
- **Crimson / Critical Alert (`#ef4444`)**: 5xx error bursts, memory exhaustion (OOM), offline hosts.
- **Purple / Accelerator & Compute (`#a855f7`)**: GPU utilization.

## Typography
- **Geist**: Labels, navigation, structural hierarchies.
- **JetBrains Mono**: Machine readouts, data values, identifiers, and monospace stats.
